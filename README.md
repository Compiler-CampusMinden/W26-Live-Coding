Dieses Repo enthält die (leicht bereinigten) Live-Coding-Sessions auf den [Vorlesungen
"Compilerbau" im Winter
2026/2027](https://github.com/Compiler-CampusMinden/CB-Vorlesung-Bachelor-W26).

Die Code-Snippets stellen eine Teilmenge der im Skript gezeigten Bausteine dar. Gelegentlich
verwenden wir live möglicherweise etwas andere Namen oder eine leicht anderen Aufbau der
Strukturen - aber wir werden inhaltlich keine Dinge tun, die nicht auch bereits im Skript
sind.

Das Repo basiert auf dem [Starter-Projekt
(Maven)](https://github.com/Compiler-CampusMinden/student-support-code-template-maven).
